# อภิธานศัพท์

หน้านี้คือที่เดียวที่**คำนิยามที่เป็นทางการ**อยู่

บทเรียนอธิบายด้วยปัญหาและตัวอย่าง ไม่ใช่ด้วยคำนิยาม เพราะการอ่านนิยามก่อนเห็นปัญหาแทบไม่ช่วยให้เข้าใจ
แต่เมื่อคุณเข้าใจแล้วและอยากได้ถ้อยคำที่รัดกุม ให้กลับมาที่หน้านี้

:::note ทำไมศัพท์เทคนิคถึงเป็นภาษาอังกฤษ

สุดท้ายคุณต้องอ่าน documentation และค้น Stack Overflow เป็น
ถ้าเราแปลทุกอย่างเป็นไทย คุณจะรู้แนวคิดแต่สื่อสารกับคนในวงการไม่ได้

หลักที่เราใช้: ครั้งแรกที่ศัพท์ปรากฏในแต่ละบท เขียนเป็น **ไทย (อังกฤษ)** จากนั้นใช้ทับศัพท์ได้เลย

:::

:::info หน้านี้เติบโตไปพร้อมบทเรียน

อภิธานศัพท์จะถูกเติมทีละคำเมื่อศัพท์นั้นถูกใช้จริงในบทเรียน
เราไม่เขียนนิยามของสิ่งที่ยังไม่ได้สอน เพราะรายการคำที่ไม่มีบริบทไม่ช่วยใครเลย

:::
