# เริ่มต้นที่นี่

Rakthan คือคอร์สเรียนวิศวกรรมคอมพิวเตอร์ภาษาไทย ที่เริ่มจากศูนย์จริง ๆ

ไม่ต้องเคยเขียนโค้ด ไม่ต้องเก่งคณิตศาสตร์ ไม่ต้องมีคอมพิวเตอร์แรง ๆ
สิ่งเดียวที่ต้องมีคือเบราว์เซอร์ — โค้ดทุกบรรทัดในคอร์สนี้รันได้ในหน้าเว็บเลย ไม่ต้องติดตั้งอะไร

## คอร์สนี้ต่างจากที่อื่นยังไง

**เราเริ่มจากปัญหา ไม่ใช่คำนิยาม**
แทนที่จะบอกว่า "ตัวแปรคือที่เก็บข้อมูล" เราจะให้คุณเจอปัญหาที่ต้องใช้ตัวแปรก่อน แล้วคุณจะเข้าใจเองว่ามันมีไว้ทำอะไร

**เราดักความเข้าใจผิด**
ทุกบทมีกล่องที่บอกว่า "คนมักเข้าใจผิดว่า..." เพราะความเข้าใจผิดที่ไม่ถูกแก้ตอนนี้ จะไปพังเอาตอนเรียนเรื่องที่ยากกว่าอีกสองปีข้างหน้า

**เราไม่บอกว่าอะไร "ง่ายมาก"**
ถ้ามันง่ายจริง คุณคงไม่ต้องมาอ่าน

**เนื้อหาเป็นภาษาไทย แต่ศัพท์เทคนิคเป็นอังกฤษ**
เพราะสุดท้ายคุณต้องอ่าน documentation ภาษาอังกฤษเป็น ถ้าเราแปลทุกอย่างเป็นไทย คุณจะเปิด Stack Overflow ไม่รู้เรื่อง

## เริ่มยังไง

เริ่มที่ **[Stage 0 — รากฐาน](/docs/stage-0-foundations/)** ตามลำดับบท 0.1 ไปเรื่อย ๆ

แต่ละบทใช้เวลาประมาณ 60–120 นาที รวม Stage 0 ทั้งหมดประมาณ 15–18 ชั่วโมง

:::tip อย่ารีบ

การอ่านผ่าน 5 บทใน 1 วัน ได้ผลน้อยกว่าการทำจริง 1 บทให้จบพร้อมแบบฝึกหัด

ทุกบทมีหัวข้อ "เช็คก่อนไปต่อ" อยู่ท้ายบท — ถ้าตอบไม่ได้ อย่าเพิ่งไปบทถัดไป

:::

## สถานะของคอร์ส

คอร์สนี้กำลังเขียนอยู่ Stage 0 ออกแบบครบ 11 บทแล้วและกำลังทยอยเขียน
ส่วน Stage 1–4 ยังเป็นเพียงร่างขอบเขต

ดูรายละเอียดที่ [แผนการเรียน](/docs/roadmap)

## เจอข้อผิดพลาด?

เนื้อหาการศึกษาที่ผิดอันตรายกว่าไม่มีเนื้อหา เพราะผู้เรียนไม่มีทางรู้ว่ามันผิด

ถ้าเจออะไรที่ดูไม่ถูก กดปุ่ม "แก้ไขหน้านี้" ท้ายบท หรือแจ้งเราทาง GitHub Issues
